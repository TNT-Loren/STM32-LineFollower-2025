# STM32 标准库 · 2025 年电赛循迹入门

本项目整理自 2025 年电子设计竞赛中的小车循迹部分，基于 **STM32F103C8 + STM32 标准外设库**，使用 **Keil MDK** 开发，适合刚接触 STM32 和循迹小车的新手学习参考。

可以从这里了解灰度传感器采集、PWM 电机驱动、编码器测速和 PID 控制如何配合实现循迹。仓库聚焦循迹相关代码，不代表完整电赛题目方案。

## 主要内容

- 七路数字循迹信号读取及偏差判断。
- 双电机 PWM 驱动、编码器测速和速度 PID。
- 根据循迹偏差调整两侧电机的目标速度。
- JY60 串口姿态数据读取及航向处理。
- OLED 显示、按键和定时器基础模块。

## 目录说明

| 路径 | 内容 |
| --- | --- |
| `User/main.c` | 程序入口、主循环和定时中断处理 |
| `Hardware/HD.c` | 七路传感器读取、循迹状态判断和速度分配 |
| `Hardware/PID.c` | 电机速度、循迹及航向 PID 参数与运算 |
| `Hardware/Motor.c`、`PWM.c`、`Encoder.c` | 电机驱动、PWM 和编码器测速 |

| `Hardware/OLED.*`、`Key.*` | 显示与按键 |
| `System/` | 延时、定时器等基础功能 |

| `START/` | 启动文件、CMSIS 和系统时钟相关代码 |
| `project.uvprojx` | Keil 工程入口 |

## 快速开始

1. 准备 STM32F103C8 开发板、双电机及驱动模块、编码器、七路循迹传感器和下载器；当前程序还初始化了 OLED 和 JY60 模块。
2. 使用 Keil MDK 打开 `project.uvprojx`，安装对应 STM32F1 器件支持，并检查编译器和下载器设置。
3. 根据各模块初始化代码核对接线、供电和传感器有效电平。
4. 编译工程并下载到开发板。建议先架空车轮验证电机方向和编码器读数，再低速测试循迹。
5. 根据自己的电机、轮径、赛道和传感器安装位置调整速度与 PID 参数。

### 主要引脚（按当前源码）

| 功能 | 引脚 |
| --- | --- |
| 七路循迹 `HD[0]`～`HD[6]` | PA2、PA3、PA4、PA5、PA8、PB3、PB4 |
| 两路电机 PWM | PB6（TIM4_CH1）、PB7（TIM4_CH2） |
| 电机 1 方向控制 | PB12、PB13 |
| 电机 2 方向控制 | PB14、PB15 |
| 编码器 1 | PA6、PA7（TIM3） |
| 编码器 2 | PA0、PA1（TIM2） |
| JY60 串口 | PB10/TX、PB11/RX（USART3，9600 波特率） |

循迹初始化会关闭 JTAG 以释放 PB3、PB4，保留 SWD 调试。其余接线请查看相应模块的初始化函数。

## 推荐学习顺序

1. 从 `User/main.c` 了解初始化和主循环。
2. 阅读 `PWM.c`、`Motor.c` 和 `Encoder.c`，理解电机如何转动、速度如何测量。
3. 阅读 `PID.c`，理解目标值、实际值与控制输出的关系。
4. 阅读 `HD.c`，理解传感器状态如何转成循迹偏差，再分配给两个电机。
5. 最后阅读 `Serial.c` 和 `JY60.c`，了解航向处理。

## 调试提示

- 基础循迹速度在 `Hardware/HD.c` 的 `BASE_SPEED` 中设置，PID 参数在 `Hardware/PID.c` 中设置。
- `main.c` 中的定时中断按 30 ms 周期执行测速和速度 PID，具体周期取决于系统时钟配置。
- `Motor.c` 的测速换算包含采样周期和编码器计数常数，更换电机或编码器后需要重新核对。
- 当前主循环会在循迹与航向处理之间切换，理解 `Keep_Ok`、`Yaw_ok` 的触发条件后再按自己的赛道修改。
- 参数和引脚对应原项目硬件，需要结合实际小车调试；本次整理未进行实物验证。

欢迎把它作为 STM32 标准库与循迹小车的入门练习，在理解代码的基础上逐步改进。
